# Zeni

A Next.js 14 (App Router) + Tailwind PWA — Zeni, a premium Gen-Z social platform
combining short/long video, messaging, calling, and offline support.

## What changed in this update

- Every screen now reads and writes **real data from Supabase** — all hardcoded
  mock arrays (creators, shorts, videos, messages, notifications, trending
  searches) have been removed.
- **Auth is enforced everywhere**: every route except Login/Sign up/Forgot
  password now requires a signed-in session, and a Supabase trigger
  automatically creates a `profiles` row the moment someone signs up.
- **Every button now works**:
  - Home: tabs (For you / Following / Trending), Follow buttons
  - Shorts: Like, Save, Share (native share sheet / copy link), Comment (opens a
    live comment sheet), Follow, Mute
  - Profile: Edit profile (modal that saves to Supabase), avatar upload, Share
    profile, real Shorts/Videos/Saved tabs, **Log out**
  - Messages: real conversation list, a full chat thread with **live/real-time**
    delivery via Supabase Realtime
  - Notifications: real notifications, auto-generated by database triggers when
    someone likes, comments, follows, or messages you
  - Search: live search across users/shorts/videos, with search history
  - Create → Upload: a full working upload flow (select → preview → thumbnail →
    title/caption/hashtags → visibility → publish) that uploads to Supabase
    Storage and inserts a real video row
  - New: a public profile page (`/profile/[username]`) with working Follow /
    Message buttons, and a long-video watch page (`/watch/[id]`) with
    like/comment/save/share and related videos

## Still stubbed (needs more backend work later)

Real WebRTC voice/video calling and true offline video caching (Service
Worker video caching) are not wired yet — everything else in the product spec
(auth, profiles, follow, likes, comments, saves, messaging, notifications,
search, upload) is now live against Supabase.

## 1. Connect Supabase

1. Create a project at supabase.com (or use an existing one).
2. In the SQL editor, run the entire contents of `supabase/schema.sql`.
   This creates all tables, the auto-profile trigger, notification triggers,
   Row Level Security policies, enables Realtime on `messages`, and creates a
   public `media` Storage bucket for videos/thumbnails/avatars.
3. In Project Settings → API, copy your **Project URL** and **anon public key**.
4. Copy `.env.example` to `.env.local` and fill in both values for local dev.

```
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT-REF.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
```

## 2. Run locally (optional)

```bash
npm install
npm run dev
```

## 3. Deploy to Netlify

1. Unzip this project.
2. In Netlify: **Add new site → Deploy manually** (drag the unzipped folder),
   or connect it as a Git repo and let Netlify build it — either works because
   `netlify.toml` already points to `npm run build` with the official
   `@netlify/plugin-nextjs` plugin.
3. Go to **Site settings → Environment variables** and add the same two
   `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` values from
   step 1.
4. Trigger a deploy (or redeploy) after adding env vars so they're baked into
   the build.

That's it — Zeni will be live and installable as a PWA.
